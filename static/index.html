⚙ 输出与项目设置 输出：默认 output · 图片：默认 output/images 未创建项目 ▾
生成的 PPTX 与 图片 ZIP 将保存到此目录；目录不存在会自动创建。
生成的页面图、图表、风格母版与参考图将保存到此目录，母版/参考图存放在该目录的 masters 子文件夹；目录不存在会自动创建。与上方 PPTX/ZIP 输出路径互不影响。
项目子文件夹命名：YYYYMMDD_项目名，页面图 / 图表落到该子文件夹下（母版仍存上面的 masters）；同日同名追加 _2/_3。A 链（手动逐页）建议先点「＋ 新建项目」；B 链上传文档时会自动创建并回填。
🔌 API 配置集 可保存多套生图 / DeepSeek 配置并随时切换 ▾
一套配置包含：生图 API 地址 / Key / 模型、DeepSeek 地址 / Key / 模型、图片尺寸与质量。切换后所有生成请求立即用新配置，不用再手动改一遍。
Key 仅保存在你浏览器本地（localStorage），不会上传到任何第三方服务器。
