# PPT 图片生成工具

一个本地网页工具：你逐页描述 PPT 内容 → DeepSeek 自动优化成高质量生图提示词 → 调用你自己的 `gpt-image-2` Key 生成 16:9 页面图片 → 自动拼成 `.pptx` 并保留原图。

## 你需要准备

| 用途 | 说明 |
| --- | --- |
| DeepSeek API Key | 用于优化提示词（模型 `deepseek-chat`） |
| OpenAI API Key | 用于生成图片（模型 `gpt-image-2`，需完成账号图片模型资质验证） |

两个 Key 都只在**你自己的浏览器本地**使用，不会上传到任何第三方。

## 一键启动（Windows）

双击运行 `start.bat`，首次会自动创建虚拟环境并安装依赖，然后打开 http://127.0.0.1:5000 。

## 手动启动

```bash
cd ppt-image-tool
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

然后在浏览器打开 http://127.0.0.1:5000 。

## 界面：三栏工作台

- **顶栏**：项目名（`YYYYMMDD_项目名`）、API 配置集下拉切换、「一键跑通」、导出 PPTX。
- **左侧栏**：① 内容（文档 → 大纲 → 文案 → 提示词）、② 素材（参考图库 / 风格母版）、③ 输出、④ 历史、⑤ 设置。再点一次当前项即可收起面板，把宽度让给画布。
- **中间画布**：每页一张缩略图卡片，显示页序、状态（待处理 / 已完成 / 失败）与候选图数量；可拖拽调整页序，勾选多页后可批量「优化选中 / 生成选中 / 删除选中」。
- **右侧检查器**：选中页的标题、内容描述、提示词、图表类型、本页参考图与候选图都在这里改。同一页多次生图会保留为候选，点缩略图即可切换用哪一张。
- **底栏**：进度条、一键跑通的 7 个步骤状态、最近一条日志。

## 使用流程

1. **填 Key**：左侧「⑤ 设置」粘贴 DeepSeek 与 OpenAI Key。有多套 Key / 中转站时，可存成「API 配置集」，在顶栏下拉里一键切换。
2. **导入内容**：左侧「① 内容」上传文档（Word / TXT / Markdown）或直接粘贴文本 → 解析文档 → 生成大纲 → 拆解文案 → 生成提示词 → 导入到画布。
3. **挑素材（可选）**：左侧「② 素材」上传参考图、指定角色与权重，或让 AI 生成风格母版。
4. **出图**：在画布上逐页点「生成」，或勾选多页批量生成，或直接「生成全部图片」。个别页面失败时点「重试失败」只重跑失败的页。
5. **导出**：顶栏「导出 PPTX」直接产出 `.pptx`；左侧「③ 输出」里还可下载图片 ZIP 与提示词 Markdown。

想一步到底就用顶栏的**「一键跑通」**：文档 → 大纲 → 文案 → 提示词 → 导入页面 → 生成图片 → 导出 PPTX 连续执行，中途可暂停，底栏逐步显示每一步状态。若画布上已有页面而没有文档，它会从「优化提示词」开始接着跑。

## 多参考图（② 素材）

支持一次上传多张参考图，并给每张指定**角色**，生成时模型会按 `image 1 / image 2 …` 的顺序逐一遵循：

| 角色 | 作用 |
| --- | --- |
| 风格母版 | 复刻配色、背景质感、字体气质、装饰母题、版式骨架、光影与留白 |
| 人物/主体 | 锁死脸型五官、发型、服装与比例 |
| 版式骨架 | 只参照构图分区与元素占比，不复制配色与文字 |
| 素材元素 | 复用图中的具体物件 / 图标 / 插画作为素材 |
| 自定义 | 使用你自己填写的说明 |

- **顺序即编号**：参考图卡片左上角的 `#1 #2 #3` 就是模型眼中的编号，用 ↑ ↓ 调整顺序即可改变编号。
- **权重**：同一类角色的多张图，权重高者优先；核心那张会自动标为「主图」。
- **启用开关**：取消勾选的图不参与本次生成，也**不占用编号**（编号自动顺延）。
- **单页覆盖**：每页可勾选本页专用的参考图子集；不勾选即继承全局参考图集。精确图表页（雷达/柱状/饼）不使用参考图。
- **首图自动母版**：勾选「自动把首图当母版」后，首图会**追加**进参考图集（角色：风格母版），不会覆盖你手动上传的图。
- **中转站兼容**：生成时依次尝试「原生多图（重复 `image[]`）→ 原生多图（重复 `image`）→ 拼贴成 contact sheet 单图 → 仅主图」，一旦降级会在提示里明确告知。可点「检测中转站多图支持」提前验证。
- **还原力度**：`input_fidelity` 选 `auto` 时，只有存在风格 / 人物参考图才用 `high`（更忠实但更贵）。

参考图统一存放在「图片保存目录」的 `masters/` 子文件夹，角色与权重记录在 `masters/refs_index.json`；参考图列表记在浏览器本地，刷新后自动恢复。

## 输出路径自定义（⑤ 设置）

- **图片保存目录**：「⑤ 设置 → ⚙ 输出与项目设置」里可自定义页面图、图表、风格母版与参考图的落盘位置（默认 `output/images`，母版/参考图放其 `masters` 子文件夹）。留空即使用默认路径。
- **输出文件保存路径**：单独控制生成的 PPTX 与图片 ZIP 保存到哪里（默认 `output` 目录）。两者互不影响。

## 目录结构

```
ppt-image-tool/
├── app.py            # 后端服务
├── chart_renderer.py # 精确图表（雷达/柱状/饼）绘制
├── requirements.txt  # 依赖
├── start.bat         # Windows 一键启动
├── static/
│   └── index.html    # 网页前端（单文件工作台）
└── output/           # 生成的图片与 PPT（自动创建）
    ├── images/       # 页面图 page_*、精确图表 chart_*，按项目子文件夹归档
    ├── masters/      # 参考图 ref_* 与风格母版 master_*，角色/权重记录在 refs_index.json
    └── *.pptx
```

## 常见问题

- **图片接口 401**：Key 无效，或 OpenAI 账号未完成 gpt-image-2 的资质验证（Organization Verification）。
- **国内直连 OpenAI 不稳定**：可在「OpenAI API 地址」里填你自用的中转/代理地址（形如 `https://xxx/v1`）。
- **生成太慢 / 太贵**：把「图片质量」调成 `low` 或 `medium`，尺寸用 `1536x1024`。
